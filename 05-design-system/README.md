## 핵심 원칙 (5)

1. 유연성을 핵심 자산으로 — 용도는 여럿, 분위기는 하나
2. 인테리어에서 비주얼을 도출 — 디자인 가구 톤이 진실의 원천
3. **기하 그래픽 앵커** — 볼드하되 정제됨(가구와 같은 바우하우스 DNA), 그루비 배제
4. **레이어 분리** — 디지털·마케팅은 컬러풀, 공간 사이니지는 블랙·화이트 물성
5. 계획/실행 분리 — 그래픽 실제 제작은 별도 승인

## 시그니처 요소

- **타입 태그**: `WORK · CLASS · GATHER` — 멀티유즈를 한 줄로.
- **레이어드 E**: 워드마크의 E를 가로 3선으로 갈라 세 쓰임(WORK·CLASS·GATHER)을 담는다. 심볼을 따로 두지 않고 **워드마크 자체가 로고**다.
- **컬러블록 + 블롭**: 색면 분할 + 유기적 셰이프(furn. 방식).
