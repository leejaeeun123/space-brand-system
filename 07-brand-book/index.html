Design System · 03

Signage

공간 사이니지 — 설치 완료·확정본(2026-08-06). 외부 3종 + 실내 2종, 안내문은 세로 A5 한 종류로 통일. 아래 사진이 실제 설치 상태다.

01 — INVENTORY

확정 5종 · 설치 실물

사인 종류를 늘리지 않는다. 새 정보는 이 5종 안에서 해결하며, 대개 자석 안내판에 종이 한 장을 더하는 것으로 끝난다.

E-1 · 외부1층 입간판T형 아이보리 철제(T자 베이스 자립) · 계단 픽토 + 워드마크 + 타입 태그 + 3F + 영문 카피 + Powered by NMWC
E-2 · 외부대문 현판무광 아크릴 · 3층 출입문 옆 벽면 · 워드마크 + 타입 태그 + 영문 카피 + Powered by NMWC
E-3 · 외부계단 중간 현판무광 아크릴 · 계단 참 간유리면 부착 · 워드마크(우측 정렬) + 계단 픽토 + 3F. 최소 정보만
I-1 · 실내자석 안내판블랙 프레임 스틸 자석보드 + 세로 A5 트레이싱지 안내문 · 원형 실버 자석 · 실버 클립 · 오렌지 마스킹테이프로 레이어드 고정
I-2 · 실내문 라벨 · 스태프룸트레이싱지 라벨 + 실버 자석 메모홀더 클립 바 · 픽토 + STAFF ROOM / Do not enter
I-2 · 실내문 라벨 · 화장실같은 문법 · 픽토 + TOILET. 문 옆 시선 높이
#사인위치물성 (확정)
E-11층 입간판건물 앞 보행 동선, 자립T형 아이보리 철제
E-2대문 현판3층 출입문 옆 벽면무광 아크릴
E-3계단 중간 현판계단 참 간유리면무광 아크릴
I-1자석 안내판실내 벽, 시선 높이블랙 프레임 스틸 자석보드
I-2문 라벨스태프룸 · 화장실 문 옆트레이싱지 + 실버 자석 클립 바
외부 3종 공통 문법 · 워드마크 가로형 단독(심볼 없음) · 타입 태그 순서는 실물 기준 WORK │ GATHERING │ CLASS · 소개 카피는 영문 단독 · 층 표기는 3F(국문 3층 아님) · Powered by NMWC는 E-1·E-2에만.
02 — PRINCIPLES

사이니지 6원칙

  • 자가안내 우선 — 무인 자동화 운영. 사인이 곧 안내 데스크.
  • 찾아오게 만들기 — 합정역 앞 3층, 1층 노출 없음. 유도가 첫 임무.
  • 도형이 글자보다 먼저 — 단 픽토는 항상 라벨과 병행.
  • 소수·정밀·절제 — 전용 52.49㎡. 종류를 늘리지 않고 같은 문법을 반복.
  • 레이어 분리 — 외부는 아이보리·화이트 면 + 잉크 레터링. 오렌지는 실내 고정 오브제에만.
  • 낮은 층고(약 2m) — 시선 1.4~1.6m, 천장 행잉·돌출 없음.

유도 시퀀스 — 3층까지 한 번도 끊기지 않게. 각 접점에 최소 1개.

길 위 보행자→E-1 1층 입간판→E-3 계단 참 현판→E-2 대문 현판→I-1 안내판 · I-2 라벨

컴포넌트 시스템 — Atom 먼저, Molecule/Organism은 조합으로. 예약 웹/앱은 추후 확장. 공간 사이니지의 확정 사양·설치 실물·안내문 규격은 Signage 탭이 정본이다.

01 — PRINCIPLES

컴포넌트 작성 원칙

  • Atom 먼저 — Molecule/Organism은 Atom 조합으로만 정의한다.
  • 이름은 실제 클래스·토큰을 그대로 — .panel .mode .floor .logo .arrow · --spine-*. 새 이름을 발명하지 않는다.
  • 색·크기는 토큰으로 지시 — "버튼은 파란색" ❌ → .mode active, var(--spine-orange) ✅.
  • 추정 금지 — 실제 화면·Figma가 생기면 그때의 이름을 그대로 채운다.
사이니지 6원칙(자가안내 · 찾아오게 만들기 · 도형이 글자보다 먼저 · 소수·정밀·절제 · 레이어 분리 · 낮은 층고)은 Signage 탭이 정본이다. 양쪽에 복사해두면 한쪽만 고쳐져 조용히 어긋난다.
