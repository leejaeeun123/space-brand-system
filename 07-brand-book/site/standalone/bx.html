03 — TONE OF VOICE

Tone of Voice

4개 보이스 속성. 각 속성은 "We are / We are not" 극성으로 정의.

따뜻한 (Warm)

  • We are: 편안하고 환대하는, 거실에 초대하는 말투
  • We are not: 과장된 친근함, 오버하는 텐션
  • ✓ "오셔서 편하게 쓰시면 돼요. 분위기는 저희가 준비해 둘게요."
  • ✗ "최고의 공간에서 잊지 못할 순간을 만들어보세요!!"

절제된 (Restrained)

  • We are: 여백을 두는, 다 말하지 않는, 고른 단어
  • We are not: 미사여구, 형용사 남발
  • ✓ "비어 있어서, 무엇이든 될 수 있어요."
  • ✗ "감성 가득한 프리미엄 럭셔리 무드의 완벽한 공간"

안목 있는 (Curated)

  • We are: 디자인을 알지만 설명충이 아닌, 슬쩍 맥락만 주는
  • We are not: 지식 자랑, 브랜드명 나열로 권위 세우기
  • ✓ "디자인 가구로 골라 채웠어요. 앉아보시면 알아요."
  • ✗ "임스, 바르셀로나, 핀율 등 디자인 거장의 명작들로 구성된…"

솔직한 (Honest)

  • We are: 한계도 인정하는(3층이에요, 넓지 않아요), 그래서 신뢰 가는
  • We are not: 다 좋다는 식의 공허한 약속
  • ✓ "넓진 않지만, 그래서 오히려 아늑해요. 6~8명 모임에 좋아요."
  • ✗ "모든 모임에 완벽한 무한대의 공간!"

스타일 규칙

  • 존댓말 기본 + 대화적 어미(~거든요, ~지요, ~돼요) 허용. 반말 금지.
  • 느낌표 문장당 1개 이하, 연속 금지.
  • 형용사 절제. 영문 병기는 타입명 등 필요한 곳만.
04 — BRAND LANGUAGE (USE / AVOID)

Brand Language (Use / Avoid)

Use — 실제로 쓰는 단어

쓴다 안 쓴다 이유
라운지 / 거실 스튜디오(기능 설명일 때만) 정서 우선
타입 (WORK · CLASS · GATHERING) 옵션 / 패키지 변신하는 공간 컨셉
대여 / 이용 렌탈 한국어 우선
모임 / 가져오다 행사 / 세팅하다 사용자 부담 낮추는 어휘

Avoid — 기존에 잘못 써온 단어

잘못 왜 안 되나 대신
프리미엄 / 럭셔리 / 감성 / 완벽 공허한 수식, 절제 위반 구체적 사실·질감으로
느낌표 연발 (!!) 오버하는 친근함 문장당 1개 이하
형용사 남발 절제·여백 위반 명사·동사 중심
렌탈 / 세팅하다 부담·기능 냄새 대여·이용 / 가져오다
옵션 / 패키지 변신 컨셉 희석 타입
바르셀로나·임스 명작 나열 지식 자랑 + 상표 리스크 구체적 질감·형태로 묘사
미드센추리 ~풍 특정 사조 라벨 — 브랜드 정체성과 불일치 디자인 클래식 ~풍 · 구체적 질감
근거 없는 낙관 솔직함 위반 한계도 인정

메시징 필러 (일관 반복 3축)

  1. "가져오기만 하세요" — 분위기·가구·세팅은 이미 준비됨.
  2. "하나의 공간, 당신의 쓰임" — 정해진 용도가 없다는 것이 곧 자유.
  3. "고른 것들의 편안함" — 큐레이션이 주는, 과하지 않은 따뜻함.
05 — SAMPLE COPY

Sample Copy

맥락 톤 예시
Hero(인스타 피드) 절제·이미지 중심 "비어 있는 거실. 오늘은 무엇이 되나요."
CTA(예약 안내) 따뜻·실용 "주말은 빨리 차요. 원하시는 시간 먼저 잡아두세요."
공간 사이니지 절제·명료 "WORK / CLASS / GATHERING — 오늘의 타입을 골라주세요."
안내문 정중·솔직 "3층이라 처음엔 살짝 헷갈리실 수 있어요. 입구 안내를 따라오시면 돼요."
문제 응대 책임·공감 "불편을 드려 죄송해요. 바로 확인하고 알려드릴게요."
타입판 — WORK 절제 "WORK — 집중하는 라운지"
타입판 — CLASS 절제 "CLASS — 비우면 스튜디오"
타입판 — GATHERING 절제 "GATHERING — 둘러앉는 라운지"
06 — TARGET AUDIENCE

Target Audience

WORKCLASSGATHERING

무인 자동화 운영 → 3종 페르소나 동등 가중. 현장 스태프가 없어 자가안내(self-guide) 니즈가 전 페르소나 공통.

타입 페르소나 Job-to-be-done 페인포인트
WORK 노마드 워커 (프리랜서·원격, 2030) "집중되면서 분위기 좋은, 카페보다 사적인 작업 공간" 카페는 시끄럽고 눈치 / 공유오피스는 삭막·월 부담
CLASS 클래스·콘텐츠 호스트 (원데이클래스·촬영, 2030-40) "가구를 빼면 장비를 세팅할 수 있는, 사진·영상이 잘 나오는 클래스·촬영 공간" 전용 스튜디오 임대료 / 일반 대관은 분위기 안 남
GATHERING 모임 주최자 (파티·소셜모임, 2030) "어색하지 않게 대화가 트이는, 우리끼리 편한 거실" 카페·식당 옆 테이블 신경 / 파티룸은 너무 '파티'

공통 인사이트: 셋 다 "분위기는 이미 완성, 나는 콘텐츠만" 을 원함(→ 필러 1과 직결). 셋 다 사진/SNS 의식 → 공간·사이니지가 "찍고 싶게" 디자인. 시간대가 달라(낮 워크 / 저녁 클래스 / 주말 모임) 가동률 순환 가능.

1차 청중: 합정·홍대권 2030, 디자인·콘텐츠 감수성 높음, SNS 활동적.

07 — POSITIONING

Positioning

마포 합정의 디자인 감수성 높은 2030에게, 타입라운지 는 사무실·클래스·모임을 한 곳에서 해결하는 멀티유즈 라운지입니다. 무미건조한 대관 스튜디오와 달리, 디자인 가구로 큐레이션된 공간이라 어떤 모임을 가져와도 이미 분위기가 완성되어 있습니다.

차별화

  1. 이미 완성된 무드 — 빈 화이트박스와 달리 세팅 노동이 없음.
  2. 변신하는 라운지 — 가벽·확장 테이블·가변 좌석으로 타입별 재구성.
  3. 합정 역세권 접근성 — 단, 3층이라 "발견의 장치(사이니지)"가 중요.
  4. 무인 자동화 운영 — 예약·결제는 앱, 현장은 사이니지 자가안내로 셀프 이용.

경쟁 맥락

  • 카테고리는 "공간 대여/대관 스튜디오"이지만, 브랜드는 "멀티유즈 라운지"로 프레이밍(스튜디오의 기능성 + 라운지의 정서).
  • 우위: 무드 완성도(vs 화이트박스) · 유연성(vs 단일 목적 카페·스터디룸) · 정서(vs 비즈니스 회의실).
08 — BRAND STORY

Brand Story

  • Hero — 콘텐츠(모임·클래스·작업)만 가져오고 싶은 합정의 2030.
  • Enemy — 무미건조한 화이트박스 대관, 옆 테이블이 신경 쓰이는 카페, 너무 '파티'스러운 파티룸.

| 렌탈 / 세팅하다 | 부담·기능 냄새 | 대여·이용 / 가져오다 |
| 옵션 / 패키지 | 변신 컨셉 희석 | 타입 |
| 바르셀로나·임스 명작 나열 | 지식 자랑 + 상표 리스크 | 구체적 질감·형태로 묘사 |
| 미드센추리 ~풍 | 특정 사조 라벨 — 브랜드 정체성과 불일치 | 디자인 클래식 ~풍 · 구체적 질감 |
| 근거 없는 낙관 | 솔직함 위반 | 한계도 인정 |

### 메시징 필러 (일관 반복 3축)
1. **"가져오기만 하세요"** — 분위기·가구·세팅은 이미 준비됨.
2. **"하나의 공간, 당신의 쓰임"** — 정해진 용도가 없다는 것이 곧 자유.
3. **"고른 것들의 편안함"** — 큐레이션이 주는, 과하지 않은 따뜻함.

## 06. Target Audience

```tl-pills
WORK | CLASS | GATHERING
```

**무인 자동화 운영** → 3종 페르소나 **동등 가중**. 현장 스태프가 없어 **자가안내(self-guide) 니즈가 전 페르소나 공통**.

| 타입 | 페르소나 | Job-to-be-done | 페인포인트 |
|---|---|---|---|
| **WORK** | 노마드 워커 (프리랜서·원격, 2030) | "집중되면서 분위기 좋은, 카페보다 사적인 작업 공간" | 카페는 시끄럽고 눈치 / 공유오피스는 삭막·월 부담 |
| **CLASS** | 클래스·콘텐츠 호스트 (원데이클래스·촬영, 2030-40) | "가구를 빼면 장비를 세팅할 수 있는, 사진·영상이 잘 나오는 클래스·촬영 공간" | 전용 스튜디오 임대료 / 일반 대관은 분위기 안 남 |
| **GATHERING** | 모임 주최자 (파티·소셜모임, 2030) | "어색하지 않게 대화가 트이는, 우리끼리 편한 거실" | 카페·식당 옆 테이블 신경 / 파티룸은 너무 '파티' |

**공통 인사이트**: 셋 다 **"분위기는 이미 완성, 나는 콘텐츠만"** 을 원함(→ 필러 1과 직결). 셋 다 사진/SNS 의식 → 공간·사이니지가 "찍고 싶게" 디자인. 시간대가 달라(낮 워크 / 저녁 클래스 / 주말 모임) 가동률 순환 가능.

**1차 청중**: 합정·홍대권 2030, 디자인·콘텐츠 감수성 높음, SNS 활동적.

## 07. Positioning

마포 합정의 디자인 감수성 높은 2030에게, **타입라운지** 는 사무실·클래스·모임을 한 곳에서 해결하는 **멀티유즈 라운지**입니다. 무미건조한 대관 스튜디오와 달리, 디자인 가구로 큐레이션된 공간이라 어떤 모임을 가져와도 **이미 분위기가 완성되어 있습니다.**

### 차별화
1. **이미 완성된 무드** — 빈 화이트박스와 달리 세팅 노동이 없음.
2. **변신하는 라운지** — 가벽·확장 테이블·가변 좌석으로 타입별 재구성.
3. **합정 역세권 접근성** — 단, 3층이라 "발견의 장치(사이니지)"가 중요.
4. **무인 자동화 운영** — 예약·결제는 앱, 현장은 사이니지 자가안내로 셀프 이용.

### 경쟁 맥락
- 카테고리는 "공간 대여/대관 스튜디오"이지만, 브랜드는 **"멀티유즈 라운지"**로 프레이밍(스튜디오의 기능성 + 라운지의 정서).
- 우위: 무드 완성도(vs 화이트박스) · 유연성(vs 단일 목적 카페·스터디룸) · 정서(vs 비즈니스 회의실).
