> 기준 구현체: `에어컨 안내문-a5` (`85:38`), `wifi 안내문-a5` (`85:3`)
> **기본형 = 세로 A5.** 새 안내문은 아래 규격 그대로 복제 → 픽토그램 + 텍스트만 교체.

## 1. 세로형 A5 (기본)

프레임 `420 × 595`, 배경 `#FFFFFF`, 이름 `{주제} 안내문-a5`

| 요소 | 사양 |
|---|---|
| 픽토그램 | SVG 벡터, 원본 비율 유지. **가로 중앙 정렬**, 세로 중심 `y ≈ 72` (블록 상단 `y 43~56` 범위에 들어옴). 폭 24~44 / 높이 30~48 — 픽토 고유 비율에 맞춰 높이 40 전후로 스케일 |
| 제목 | Paperlogy **4 Regular** / `15px` / 자간 `0.45px` (3%) / `#16130F` / 가운데 정렬 / 1줄. 상단 `y = 픽토 하단 + 18` |
| 본문 | Paperlogy **3 Light** / `11px` / 행간 `16px` / 자간 `0.44px` (4%) / `#16130F` / 가운데 정렬. 상단 `y = 405` 고정, 위쪽으로 늘지 않고 아래로 흐름 |
| 로고 락업 | `Group 2` = TYPE LOUNGE 워드마크 가로형, `76 × 8.46`, 가로 중앙(`x 172`), `y = 539` (하단 여백 47.5) |

본문 규칙
- **2줄이 기본, 최대 3줄** — 권장값이지 제약은 아니다. 넘겨야 할 내용이면 그대로 진행한다(`gen_notice.py`는 경고만 남기고 생성한다). 프레임을 늘리거나 폰트를 줄이는 것은 금지.
- 문장 단위로 줄바꿈. 원고에서 `▎`는 **줄바꿈 지점** 표시(렌더에 남기지 않음).
- 한 줄 최대폭 **325px** (Figma 기준, 재은 확정). 넘으면 경고만 남고 생성은 진행된다.
- 어투는 `notice-copy.md`의 `~해요/~시면 돼요` 존댓말 유지.
- QR·부가 이미지가 필요하면 본문 위에 `60 × 60`, 가로 중앙, `y = 329` (wifi 안내문 기준).

## 2. 가로형 A5 (예외)

프레임 `595 × 420`. 픽토·제목이 좌상단(`x ≈ 43~60`, 픽토 하단 `y ≈ 356`), 본문 좌측 정렬 `x = 254`, 로고 `x = 367 / y = 336`.
**용도로 구분한다: 벽에 직접 붙이는 안내문만 가로형.** 그 외 전부 세로형(트레이싱지 → 자석판 레이어드).
가로형은 별도 요청이 있을 때만 만든다 — 요청 없으면 묻지 않고 세로형으로 진행.

## 3. 픽토그램

보유 세트: `04-signage/picto-*.svg` (18종, `-current`/`-white` 변형 포함)

```
wifi  tv  aircon  bluetooth  speaker  power  phone  notouch  no
shoe  trash  toilet  room  stairs  coffee  bbq  umbrella  extinguisher  nosmoke
```

없는 주제면 **신규 픽토를 먼저 만든다** — `gen_new_pictos.py` 방식(선 두께 `2.7`, `viewBox` 정사각, `color:#16130F` 잉크 기본값)으로 세트 톤을 맞추고, `picto-{name}.svg` + `-current` + `-white` 3종으로 저장 후 `pictograms.md`·시안 HTML에 추가.

## 4. 신규 안내문 생성 절차

1. 원고 확정 (제목 1줄 + 본문 문장, `▎`로 줄 구분) → `notice-copy.md`에 추가
2. 픽토그램 확인 → 없으면 생성 (3절)
3. Figma `최종` 페이지에 세로 A5 프레임 생성, 1절 규격대로 배치
   - 기존 프레임 오른쪽으로 `x + 452` 간격으로 나란히 배치
4. 출력 사양: 세로 A5 트레이싱지 / 가로 A5 두꺼운 종이
