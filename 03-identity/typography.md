## 2. 자간 규칙 (확정)

**본문 포함, 영문·국문 모두 +3%** (Figma 기준 · CSS `letter-spacing: 0.03em`).
크기·역할·언어와 무관하게 한 값으로 통일한다. 실제 안내문 작업을 이 값으로 했다.

### 로고 자간과 혼동하지 않는다

아래 값은 **로고·타입 태그를 그릴 때** 쓴 것이고, 일반 글씨의 자간 규칙이 아니다.
둘 다 이미 SVG 아웃라인으로 구워져 있어 이제 와서 자간을 지정할 일이 없다.

| 대상 | 제작 자간 | 어디에 |
|---|---|---|
| 워드마크 영문 | **−2%** | `logo-wordmark-*.svg` (아웃라인 확정) |
| 워드마크 국문 | 0% | 〃 |
| 타입 태그 (WORK·CLASS·GATHERING) | **+0.05em** | `mode-*.svg` (아웃라인 확정) |

폐기된 것은 **이 값들을 일반 타이포에까지 적용하던 규칙**이다 — 이전 표의
"라벨·타입 태그(대문자) +0.12~0.14em"이 그 경우다.

## 4. 타입 태그 (시그니처)

```
WORK · CLASS · GATHER
```
- Paperlogy **400** / 대문자 / 가운뎃점 구분. 자간 +3%. 로고 3선(레이어)과 개념적으로 연결.

## 5. 운용 규칙

- **가운데 정렬 기본** — 안내문 위주 레이아웃(위/아래 배치, 중앙 정렬). “심플한 레이아웃” 키워드.
- 디스플레이는 크고 과감하게, 글자 조형 자체가 그래픽.
- 강조는 굵기(600)·컬러블록으로. 밑줄·그림자 금지.

## 6. 접근성

- 본문 최소 16px. Paperlogy는 개성이 있어 **초소형 라벨**에선 크기 확보 필수(≥12px).
- 초대형 디스플레이는 대비 확보.
